2. libvirtd 不自启的根因：模块化守护进程在抢班夺权
Fedora 41+ 默认启用了模块化 daemon（virtqemud、virtnetworkd 等一堆），它们和老的 libvirtd 互相冲突——开机时两边抢启动，模块化赢了就把 libvirtd 干掉，所以每次重启都“已启用但没运行”。解法：把模块化全家禁掉，只留 libvirtd：
bash
# 一次性禁用所有模块化 daemon 的 service 和 socket
sudo systemctl disable --now \
  virtqemud.service virtnetworkd.service virtstoraged.service \
  virtnodedevd.service virtnwfilterd.service virtsecretd.service virtinterfaced.service \
  virtqemud.socket virtqemud-ro.socket virtqemud-admin.socket \
  virtnetworkd.socket virtnetworkd-ro.socket virtnetworkd-admin.socket \
  virtstoraged.socket virtstoraged-ro.socket virtstoraged-admin.socket \
  virtnodedevd.socket virtnodedevd-ro.socket virtnodedevd-admin.socket \
  virtnwfilterd.socket virtnwfilterd-ro.socket virtnwfilterd-admin.socket \
  virtsecretd.socket virtsecretd-ro.socket virtsecretd-admin.socket \
  virtinterfaced.socket virtinterfaced-ro.socket virtinterfaced-admin.socket 2>/dev/null
# 让 libvirtd 独占并立即启动
sudo systemctl enable --now libvirtd.service
# 验证
sudo systemctl is-active libvirtd    # active
systemctl is-enabled libvirtd        # enabled
 
然后重启实测一次——重启后不开终端手动 start，直接跑：
bash
sudo systemctl is-active libvirtd

正确解法：用 git 的全局 URL 重写规则，让所有 github.com 请求自动走代理，一条配置解决主仓库+全部子模块。
1. 设置全局 URL 重写（核心）
bash
git config --global url."https://gh-proxy.com/https://github.com/".insteadOf "https://github.com/"
 
这个配置让 git 以后所有访问  https://github.com/...  的操作（包括子模块、包括其他仓库）都自动改写成走  gh-proxy.com ——不用改任何脚本和 .gitmodules。
你之前在 ovmfpatch.sh 里手改的前缀可以不用管了（反正我们手动克隆，脚本那行不再执行；即使执行也不会双重拼接前缀，重写规则只匹配以 github.com 开头的 URL）。
2. 清掉残缺目录，重新克隆
bash
cd ~/下载/Nika-Read-Only-main
sudo rm -rf ovmfbackup ovmf
# 浅克隆主仓库 + 子模块全部浅克隆 + 8 线程并行拉子模块
git clone --recursive --single-branch --branch edk2-stable202602 \
  --depth 1 --shallow-submodules -j 8 \
  https://github.com/tianocore/edk2.git ovmfbackup
 
 --shallow-submodules ：每个子模块也只拉 1 层快照（openssl 全历史好几 GB，浅克隆只要 ~100MB）
​
 -j 8 ：8 个子模块并行下载

4.配置evdev直通（在Linux电脑上）
用以下工具找到你的鼠标和键盘：
ls -l /dev/input/by-id/
编辑：/etc/libvirt/qemu.conf

cgroup_device_acl = [
        "/dev/null", "/dev/full", "/dev/zero",
        "/dev/random", "/dev/urandom",
        "/dev/ptmx", "/dev/kvm", "/dev/kqemu",
        "/dev/rtc", "/dev/hpet",
        "/dev/input/by-id/usb-COMPANY_USB_Device-if01-event-mouse",
        "/dev/input/by-id/usb-SONiX_USB_DEVICE-event-kbd",
        "/dev/input/event0",
        "/dev/input/event1",
        "/dev/input/event2",
        "/dev/input/event3",
        "/dev/input/event4",
        "/dev/input/event5",
        "/dev/input/event6",
        "/dev/input/event7",
        "/dev/input/event8",
        "/dev/input/event9",
        "/dev/kvmfr0",
        "/dev/userfaultfd"
]
如上所述，包含 ，替换 ，以及每个符号链接的路径。cgroup_device_aclevent-kbdevent-mouse/dev/input/eventX
Restart libvirtd：
sudo systemctl restart libvirtd
需要时切换输入LEFT_CTRL+RIGHT_CTRL。
